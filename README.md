# Writely

Enterprise-grade microservices-based assignment marketplace.

## Architecture

- **Apps**: Next.js and React SPAs for different user roles.
- **Services**: Backend microservices handling specific domains.
- **Packages**: Shared logic, UI, and database access.
- **Infra**: IaC and deployment configurations.

## Getting Started

1. Install pnpm: `npm install -g pnpm`
2. Install dependencies: `pnpm install`
3. Start dev environment: `pnpm dev`

Escrow rules
Single payment
Full amount held at order acceptance. Released in one shot on seeker approval or 48h auto-approve window.
Milestone payment
Order split into milestones (e.g. outline, draft, final). Each chunk released independently as each milestone is approved.
Failure & refund handling
Payment failure
Retry × 3 → fallback gateway → notify seeker
Cancellation refund
Full refund before work starts · partial after
Dispute raised
Escrow frozen → admin mediates → split decision
Fraud detection
Velocity checks · card fingerprinting · ML flags
Assignment order state machine
DRAFT → OPEN → BIDDING → ACCEPTED → IN_PROGRESS → SUBMITTED → IN_REVIEW → REVISION → APPROVED → COMPLETED
CANCELLED ← OPEN / BIDDING / IN_PROGRESS → DISPUTED → RESOLVED
